A complete workspace

Everything you expect from a PDF app, without the upload button.

OpenPDF Studio combines a fast reader with the tools people actually use every day. Each feature runs locally with open-source libraries and browser APIs.

Read and navigate

Sharp rendering, zoom, rotation, thumbnails, outline, metadata, text selection and search with highlights.

Annotate and edit

Highlights, comments, freehand drawing, shapes, text, images, visual signatures and whiteout. Move, undo and export flattened.

Organize pages

Reorder by drag and drop, delete, duplicate, extract, split, merge and rotate pages while preserving metadata.

Fill forms

AcroForm text, checkbox, radio, dropdown and list fields. Update appearances, flatten fields and download a filled copy.

OCR locally

Portuguese and English text recognition with Tesseract.js. Export text or build a searchable PDF with an invisible text layer.

Protect with AES-256

Open and owner passwords, print/copy/edit permissions, and password removal — all encrypted in browser memory.

Redact and compress

Mark areas and apply irreversible rasterized redaction with metadata removal. Compress scans with configurable DPI and JPEG quality.

Compare versions

Visual page-by-page diff with side-by-side previews and red highlights. Useful for contracts, revisions and proofing.

Privacy by architecture

Your document never leaves the tab.

There is no document backend. Parsing, rendering, editing, OCR, encryption and comparison happen in the browser using PDF.js, pdf-lib, Tesseract.js and WebAssembly.

No upload, no account

No login, no subscription, no telemetry. Open a PDF and it stays in memory on your device.

Works offline

Installable PWA. The app shell and viewer work without a network after the first load.

Auditable source

MIT licensed and public on GitHub. Inspect the code, self-host the static build or fork it.

Verify it yourself

  1. Open your browser DevTools (F12) and go to Network.
  2. Open or drop a PDF and use annotations, OCR or protection.
  3. Observe that no request contains the document bytes.
  4. Switch offline and keep working on the open document.

Designed for local-first work

Contracts, medical records, invoices, research and personal documents should not need a cloud round-trip just to be read or annotated.

PWA · Offline · Installable

A desktop-class PDF workspace that installs like an app.

OpenPDF Studio is a Progressive Web App. Install it from your browser, pin it to your dock or home screen, and keep working without a connection.

Install in three steps

  1. Open the app in Chrome, Edge, Brave or another Chromium browser.
  2. Use the install icon in the address bar, or the “Install app” button on this page.
  3. Launch it from your desktop or home screen. The shell is cached for offline use.

Offline behavior, stated honestly

  • Reading, annotations, page operations, forms, protection and comparison work offline.
  • OCR models are cached after first use. Use OCR once online before going offline.
  • PDFs themselves are never cached by the service worker.

Questions, answered

What you should know before using it.

Is OpenPDF Studio free and open source?

Yes. It is MIT licensed and the source is public on GitHub. There is no account, subscription, document service or paid tier.

Do my PDFs get uploaded to a server?

No. Parsing, rendering, annotations, forms, OCR, redaction, compression, encryption and comparison run in your browser. The document never leaves your device.

Does it work offline?

Yes, as a PWA. After the first load the app shell and viewer are cached. OCR language models are cached after first use, so run OCR once online before relying on offline OCR.

Can it replace Adobe Acrobat?

It covers the everyday workflow with open-source equivalents: reading, annotation, page organization, forms, OCR, redaction, compression, comparison and AES-256 protection. It does not implement certified PAdES signatures, PDF/A preflight, XFA, 3D/multimedia, Adobe DRM or Document Cloud.

Does it support certified digital signatures?

The current signature tool is a visual signature image, not a cryptographic PAdES/ICP-Brasil signature. Certified signatures are on the roadmap and require a certificate provider.

How does OCR work without a server?

OCR uses Tesseract.js compiled to WebAssembly. Portuguese and English models are static assets processed locally. No page image is uploaded.

Is there a native desktop app?

Yes. OpenPDF Studio Desktop 0.2.0 is a separate native Rust app built with egui and PDFium, not a Tauri or webview wrapper. It currently focuses on native viewing, search, tabs, thumbnails, rectangle annotations, sticky notes and page extraction. OCR, AES-256, redaction, compression, comparison and certified signatures remain on its roadmap; the web app covers them today.

Independence

Inspired by the feature surface, not by the code.

OpenPDF Studio is an independent project, not affiliated with Adobe. It does not bypass licenses, DRM or paid features. The goal is to make the everyday PDF workflow private, portable and auditable.
